# Farmer app screen designs (reference)

Static HTML mockups of five farmer screens for the Flutter app (390x844 phone size).
Open any file in a browser; links between screens work.

- Home.html — home dashboard
- Animals.html — my animals list
- AnimalProfile.html — animal profile and health history
- FindVet.html — find a vet (manual area + location consent)
- Assistant.html — AI livestock assistant

All names, animals, vets, dates and announcements are sample data.
These are visual references only: implement the screens in Flutter, do not ship this HTML.
