## How to use

1. Requirement IDs come from `software-requirements-specification.md` (FR-<MODULE>-<NN>, NF-<NN>).
2. After Phase 2+ implementation starts, fill Design, Implementation, and Test columns with real references (file paths, test IDs, `docs/03_testing/` evidence).
3. Update at every phase gate; final version is an appendix to the project report.
